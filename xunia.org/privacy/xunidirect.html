XuniDirect Privacy Policy

Effective date: September 4, 2026

Limited Use disclosure

The use of information received from Google APIs by XuniDirect will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

What XuniDirect accesses

XuniDirect requests Google OAuth authorization to access the signed-in user's YouTube account for the extension's single purpose: reviewing and managing that user's own YouTube subscriptions.

The extension may process subscription metadata returned by the YouTube Data API, including channel title, channel identifier, subscription identifier, and the date/time the subscription was created.

How the data is used

  • to display the user's current subscriptions inside the extension;
  • to filter subscriptions by date or channel name;
  • to allow the user to select or deselect subscriptions;
  • to perform unsubscribe actions only after explicit user confirmation;
  • to display success, failure, and quota status to the user.

Storage and transmission

The current XuniDirect design is local-first. Subscription data is processed in the extension UI and requests are sent directly between the browser and Google APIs over HTTPS. XuniDirect is not designed to send subscription lists to a developer-controlled analytics, advertising, or data-broker service.

Chrome and Google may cache authentication information as part of the Chrome Identity and Google OAuth mechanisms. XuniDirect may use Chrome extension storage for local user-interface preferences such as date or text filters.

What XuniDirect does not do

  • does not collect browser history;
  • does not sell Google user data;
  • does not use Google user data for personalized advertising;
  • does not transfer YouTube subscription data to advertising platforms or data brokers;
  • does not allow background autonomous bulk unsubscribe without user confirmation;
  • does not target or modify another person's YouTube account.

User control

Users choose when to connect their Google account, when to scan subscriptions, which subscriptions to select, and whether to confirm an unsubscribe operation. Users can disconnect the extension and revoke Google account access through their Google Account security settings.

Data retention

XuniDirect is designed not to retain a server-side copy of the user's subscription list. Local extension preferences may persist in Chrome until the user clears extension data or uninstalls the extension.

Security

Google API requests are made over HTTPS. XuniDirect does not embed a Google OAuth client secret in the browser extension package.

Changes

If XuniDirect's data practices materially change, this policy and the Chrome Web Store disclosures should be updated before the changed data practices are introduced to users.

Contact

Support and publisher contact information will be provided in the Chrome Web Store listing and XUNIA project site before public release.

XuniDirect is a XUNIA / Black House ecosystem project. Google, YouTube, Chrome, and Chrome Web Store are referenced as external platforms and APIs; no endorsement or partnership is implied.
