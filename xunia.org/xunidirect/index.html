XuniDirect
YouTube Cleaner

A user-controlled Chrome extension for reviewing and cleaning up the signed-in user's own YouTube subscriptions. XuniDirect uses the official YouTube Data API instead of page-click automation.

Single purpose

Help a user inspect, filter, select, and unsubscribe from their own YouTube subscriptions by subscription date or channel name, with an explicit preview and confirmation before any unsubscribe action.

Date filtering

Filter subscriptions by when the user subscribed.

Selection preview

Review exactly which channels match before any change occurs.

Human confirmation

Bulk unsubscribe requires an explicit user confirmation.

Official API

Actions are performed against the authenticated user's account through the YouTube Data API.

Privacy

XuniDirect is designed as a local-first extension. It does not collect browser history, does not sell Google user data, and does not use Google user data for advertising.
