# The Black House — Resilience Simulation

Free, customer-testable Three.js + TypeScript civil-defense exercise simulator for The Black House / XUNIA ecosystem.

## Stack
- Three.js
- TypeScript
- Vite
- Static hosting compatible with GitHub Pages / Cloudflare Pages

## Reasoning integration
The UI exposes a GPT-DOUG-LLM / VIRGINIA-LLM briefing surface. In this build it is a deterministic local reasoning interface so the simulator runs without paid model APIs. It emits AIP/Ontology-ready civil-defense guidance and can later be connected to authorized XUNIA model services.

## Scope
Training, resilience, hospital surge, infrastructure risk, shelter readiness, mutual aid, and AIP/Ontology scenario workflows only.
